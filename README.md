# memonow

「その瞬間のことを一文で残す」個人向けのAndroidメモアプリです。
画面下から投稿すると、古い記録が上、新しい記録が下に並びます。
記録は端末内に保存され、アプリを閉じても残ります。

## できること

- 日本語・改行を含む一文メモを素早く投稿
- 本文・日時を時系列で読み返し、本文を編集、確認して削除
- JSONファイルへの手動バックアップと全件復元
- 任意で市区町村名・天気・気温を自動付与（初期OFF）

## インストール

**Android 8.0以降**が対象です。アカウント登録は不要です。
[最新の正式版をGitHub Releasesから取得](https://github.com/YanTKYS/memonow/releases/latest)してください。
APKと対応する`.sha256`を取得し、チェックサム・署名を確認してインストールします。
確認方法は[配布ファイルと更新の案内](docs/releasing.md)にあります。

更新前に、既存データをJSONへ保存して安全に保管してください。
同じ署名の正式版は上書き更新できます。
debug版や別の署名から切り替える場合は、[データ移行](docs/backup.md)を先に確認してください。

## 基本の使い方

1. 下部の「いまの一文」に入力し、「送信」を押します。
2. 過去のメモは上へスクロールして読み返します。
3. 投稿の「編集」で本文を変更し、「削除」は確認して実行します。

投稿は本文を先に保存します。保存に失敗した場合は入力が残ります。
位置・天気の取得を待たずに次のメモを入力できます。

### バックアップと復元

画面右上の「バックアップ」から「JSONを保存」を選び、保存先・ファイル名を指定します。
完了表示と件数を確認し、定期的に別の安全な場所にも保管してください。
復元は「JSONから復元」でファイルを選び、件数と置換警告を確認して実行します。
詳しくは[保存・復元・別端末移行](docs/backup.md)を参照してください。

### 位置・天気を付ける

画面右上の「設定」で説明を読み、「位置・天気の自動付与」をONにして、おおよその位置を許可します。
画面表示中の新規投稿だけが対象です。取得できた属性が後から加わります。
設定の「最後の自動付与結果」で進行・終了理由を確認できます。
詳しくは[位置・天気とプライバシー](docs/location-weather.md)を参照してください。

## データとプライバシーの要点

- **復元は全件置換**です。追記・マージではないため、先に現在の記録を退避してください。
- **JSONは暗号化されない平文**で、本文・日時・地名・天気を含みます。保存先・共有先を確認してください。
- 記録の正本は端末内です。自動同期・定期バックアップはなく、アンインストールやストレージ消去で記録は消えます。
- 位置・天気をONにすると、**丸めた位置情報をAndroidの地名解決サービスとOpen-Meteoへ送信**します。サービス側にはIPアドレスも伝わります。
- 座標は端末DB・JSONへ保存せず、本文・履歴・投稿IDはこれらのサービスへ送信しません。
- 位置・天気は権限・通信・OSサービスによって欠けることがあります。取得失敗でも本文は残ります。

データ損失を避ける手順は[バックアップ](docs/backup.md)、外部送信・取得条件の詳細は[位置・天気](docs/location-weather.md)にまとめています。

## 天気データの出典

**Weather data by [Open-Meteo.com](https://open-meteo.com/)**、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。
天気は投稿時刻に近いモデルの推定値です。
無料APIは非商用利用向けで、商用利用等は提供元の条件を再確認してください。
[利用条件・送信項目の詳細](docs/location-weather.md)も確認してください。
