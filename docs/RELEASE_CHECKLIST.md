### 当時のDraft候補と正式版のバージョン（履歴）

`version.properties` は `versionName=0.1.0` / `versionCode=1`、正式タグは `v0.1.0` が対応します。
preview候補もpublish時も同じファイルを読み、現行Workflowは公開時のversionCode上書きをしません。
previewは `test-v*` の未公開Draft、publishは同じ実行内で正式 `v*` タグを自動作成して公開します。
既存のテストDraftをそのまま公開する手順ではありません。再ビルドAPKが候補とバイト単位で一致する保証はありません。

候補と正式版がともにcode 1では、増加するversionCodeによる更新・データ保持の検証にはなりません。
実機の候補が別バイナリなら、同じcodeでの差し替えを通常の更新互換性の証拠にしないでください。
候補からの移行方法と配布済みバージョンを確認し、必要なら正式版のバージョン・ノート・タグを揃えて見直します（本PRでは変更しません）。
codeを増やす更新テストは実データから隔離した環境で行い、code 2等のテスト後に正式code 1へ戻すダウングレードを実データ端末の前提にしないでください。
正式公開後の更新は必ずcodeを増やします。
