# memonow v0.1.0

「その瞬間のことを一文で残す」個人向けライフログアプリの初版です。
Android 8.0以降が対象です。アカウント登録は不要です。

- 日本語・複数行の投稿、端末内保存、編集・確認付き削除。
- 古い記録が上、新しい記録が下の履歴表示。
- 任意の位置・天気自動付与（初期OFF、おおよその位置のみ）。新鮮なキャッシュとOSの位置取得APIを利用し、連続投稿時の取得を改善。
- 設定画面で自動付与の進行・終了理由を確認。地名が取得できなくても天気取得を継続。
- UTF-8 JSONへの手動バックアップと、検証・確認付きの全件復元。
- 本文上限10万UTF-16単位の事前チェックと、バックアップ容量・件数の警告。

## インストール・更新

APKと対応する`.sha256`を取得し、チェックサム・署名証明書を確認してください。
同一署名のrelease版からは、同じapplicationIdと増加するversionCodeで上書き更新します。
テスト用Draft候補も `0.1.0` / code `1` です。正式版と同じcodeの候補からの差し替えは、
codeを増やす通常の更新とは区別し、公開前チェックリストで移行方法を確認してください。

debug版からは署名が異なり、原則そのまま上書きできません。先にJSONを保存して別のテスト環境で復元を確認し、
元のアプリ・記録を削除する前にバックアップを確保してください。アンインストールで端末内記録は消えます。

## 注意点

- 記録の正本は端末内です。JSONは暗号化されない平文で、自動同期・定期バックアップはありません。
- JSONの上限は10MiB・1万件・本文各10万UTF-16単位。復元は追加マージではなく全件置換です。
- 位置・天気は任意の推定情報で、権限・通信・OSサービスによって欠損することがあります。座標はDBへ保存しません。
- Weather data by [Open-Meteo.com](https://open-meteo.com/)、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。無料APIは非商用向けです。
- Play Store配布、アプリ内更新、クラウド同期は含みません。

操作・データ移行・署名確認はREADME、実機での確認項目は`docs/RELEASE_CHECKLIST.md`を参照してください。
