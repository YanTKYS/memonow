# memonow v0.1.6

上部のカレンダーアイコンから、投稿のある日を選んでその日の記録を読み返せるようにしました。

- 日本語の年月・曜日を表示し、前月/翌月・今月・最新の記録の月へ移動できます。投稿がある日をドットと件数で示します。
- 日付別表示では年月日・件数と「全件表示」を表示し、通常の編集・削除・気分表示も使えます。
- 日付別表示中の送信も現在時刻で保存し、成功時は全件表示へ戻って新しい投稿へ移動します。最後の投稿を削除した場合や全件復元後も全件へ戻ります。
- 端末のタイムゾーンで日付を分類し、一覧の日時表示と揃えます。画面の状態再作成では選択日とスクロール位置を保持します。
- 「バックアップ」「設定」は右上の「︙」メニューへ移動しました。

0.1.6 / versionCode 7です。Room v3・JSON v2と旧6種類の気分、旧JSON互換性を維持します。カテゴリや新しい権限・外部通信は追加しません。
アプリ内更新・署名検証・自動公開方式は維持しています。設定からのGitHub Releases更新成功はユーザー報告済みですが、本作業で0.1.6への実機更新を実施したものではありません。

実機IME/TalkBack・OSタイムゾーン変更・正式APKの更新後のデータ保持は今回未確認です。
[操作ガイド](../calendar.md)と[本版の確認記録](../RELEASE_CHECKLIST_v0.1.6.md)を参照してください。
オーナーがmainへマージすると自動公開対象となります。実装担当はマージ・タグ作成・先行公開を行いません。
