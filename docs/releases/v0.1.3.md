# memonow v0.1.3

設定の入口を「位置・天気」と「アプリの更新」に整理しました。位置・天気のON/OFF・診断・説明はそのまま利用できます。

- 利用者が「最新版を確認」を押した場合だけ、固定のGitHubリポジトリの正式版を匿名で確認します。
- 新しい版のAPKを上限付きで取得し、SHA-256・APK署名・現在の証明書との一致・package/版/codeを確認します。
- 検証成功後、利用者がAndroidの提供元許可とOSインストーラーで承認して上書き更新します。強制更新・自動インストールは行いません。
- 取得の取消や検証失敗時は部分ファイルを破棄し、未検証APKをOSへ渡しません。

0.1.3 / versionCode 4です。同一署名・applicationIdの更新を前提とし、Room/JSON・投稿・位置天気の仕様は変更しません。
インストール案内用にREQUEST_INSTALL_PACKAGESを追加します。許可の変更は利用者が端末の設定で行います。
投稿・位置・履歴は更新確認で送信しません。通信先には通常のIPアドレス等が伝わります。更新前にJSONを退避してください。

既存v0.1.2からはGitHubの正式Releaseを使った手動更新が必要です。この機能による自己更新はv0.1.3以降からの次回更新で確認します。
初回時点の完全な自己更新、OEM別の許可/インストーラー、更新/取消後のデータ保持は実機未確認です。
[操作と検証の詳細](../updating.md)と[本版の確認記録](../RELEASE_CHECKLIST_v0.1.3.md)を参照してください。レビュー後のオーナーのmainマージが自動公開の承認となり、実装担当は先行公開しません。
