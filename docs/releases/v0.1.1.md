# memonow v0.1.1

位置・天気の自動付与が一時的に失敗する場合や、連続投稿した場合の回復を改善します。

- 同時2件まで取得し、追加6件を最大30秒待機させます。待機枠を超えた場合も本文は保存されます。
- 一時的な位置・地名・天気取得の失敗は、2秒後に1回だけ自動再試行します。取得済みの属性は再取得・上書きしません。地名・天気だけの再試行は有効な一時座標を再利用し、位置取得が失敗したときだけ位置を取り直します。座標の有効期限が切れた場合は終了します。
- Android 13以降の地名取得を非同期化。地名が欠けても天気の取得を続けます。
- 設定の最終結果に順番待ち・再試行中・試行回数を表示します。最新の処理だけを表示し、投稿別の履歴は保存しません。

## 更新とデータ

versionNameは0.1.1、versionCodeは2です。正式版0.1.0と同じ署名・applicationIdでの上書き更新を前提とします。
更新前に既存の記録をJSONに保存し、安全に保管してください。更新時のデータ保持は実機未確認です。
Room v2とJSON形式は変更しません。本文・日時・ID・表示順・既存の属性を保持します。

自動付与は画面表示中・設定ON・おおよその位置権限ありの場合だけです。画面離脱・設定OFF・復元で中断し、再開時に古い投稿を取り直しません。
投稿から2分を超えた場合は補完せず、天気の時刻差は引き続き最大20分です。位置の鮮度・精度条件も維持します。
位置サービスOFF・権限なし・地名非対応・不正応答などは再試行せず、取得を保証しません。座標は保存しません。
JSONは平文・全件置換で、自動同期やバックグラウンド追跡はありません。
