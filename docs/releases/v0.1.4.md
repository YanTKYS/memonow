# memonow v0.1.4

投稿に任意の気分を添えられるようにしました。

- 「気分（任意）」の6候補から、うれしい・楽しい・怒り・悲しい・普通・疲れたを1タップで選べます。同じ項目をもう一度押すと解除できます。
- 気分を選ばず本文だけでも送信できます。保存成功時に本文と気分をリセットし、失敗時や画面回転では保持します。
- 一覧に気分を表示し、「編集」で選び直し・解除できます。作成日時・ID・順序や位置・天気は保持します。
- 既存の投稿は気分なしで移行します。JSONは気分を含む新形式で保存し、従来のJSONも気分なしとして復元できます。

0.1.4 / versionCode 5です。同一署名・applicationIdの正式APKで0.1.3から上書き更新できます。更新前にJSONを退避してください。
Room DBはv3へ非破壊移行し、JSONはv2出力・v1/v2入力です。旧アプリは新しいv2 JSONを読めないため、旧JSONも保管してください。
気分は端末内と利用者が手動保存する平文JSONに含めます。新たな権限・通信・自動取得・検索/集計は追加していません。
アプリ内更新・署名検証・正式Release運用は変更しません。

小さい画面や大きい文字・キーボード併用の実機操作、同一署名の実APK上書き後のデータ保持は未確認です。
[本版の確認記録](../RELEASE_CHECKLIST_v0.1.4.md)と[バックアップの互換性](../backup.md)を参照してください。
オーナーがmainへマージすると自動公開対象となります。実装担当はマージ・タグ作成・先行公開を行いません。
