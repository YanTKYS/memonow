# memonow v0.1.2

位置取得が2回ともタイムアウトした実機報告を受けた修正版です。天気APIより前の位置取得段階で失敗したことは確認できていますが、端末固有の原因は未特定です。

- Android 12以降では有効な統合位置（Fused）・ネットワーク位置を同時に最大2候補だけ試し、最初の有効な位置を採用します。片方の10秒待ちが他方の開始を遅らせません。採用後は残りを解除します。
- 設定の最終結果に、候補ごとのキャッシュ状態、位置なし応答、期限内の応答なし、採用・解除などを表示します。固定ラベルの一時状態のみで、座標・詳細住所・本文・ID・URL・IP・例外ログ・履歴を記録しません。
- 位置の経過2分以内・精度10km以内、投稿後2分、有限再試行、画面離脱中断は維持します。地名・天気だけの再試行は有効な丸め済み一時座標を再利用します。

0.1.2 / versionCode 3です。公開済み0.1.1と同一署名・applicationIdで更新します。更新前に既存データをJSONへ退避してください。
本文の先行保存・Room v2・JSON形式・既存属性の保持は維持します。追加の位置権限・Google Play services依存・座標の永続化はありません。
[オーナーの実機報告](https://github.com/YanTKYS/memonow/issues/23#issuecomment-6443851794)では位置・天気の付与に成功し、成功時の取得が以前より体感的に速いとされています。実測時間・継続成功率・他端末での再現性・更新時のデータ保持は、この報告では未確認です。取得を保証するものではありません。

実施結果と未確認事項は[確認記録](../RELEASE_CHECKLIST_v0.1.2.md)、現行の公開運用は[公開ガイド](../releasing.md)を参照してください。
