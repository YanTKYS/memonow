# memonow v0.1.5

気分の選択を😊 😠 😢 😮‍💨の4種類の絵文字へ簡素化しました。説明ラベルを常時並べず、通常は見出しと候補を1行に収めます。

- 気分は任意です。同じ絵文字をもう一度押すと未選択へ戻せ、本文だけでも投稿できます。
- 選択中は背景・太枠・チェックで示します。各ボタンは48dpのタップ領域を確保し、読み上げ用の英語名/日本語名・選択状態を付けています。
- 一覧も絵文字だけで表示し、読み上げ上の意味を維持します。
- 過去の「楽しい」😆（fun）・「普通」😐（normal）は元のIDで残ります。編集の「以前の気分」で確認でき、本文だけの編集では保持し、4候補へ選び直すか「解除」でのみ変更します。

0.1.5 / versionCode 6です。Room v3・JSON v2、旧JSON v1の読み取りと旧6種/nullの保存・復元を維持します。既存データの変換・消去や新しいマイグレーションはありません。
アプリ内更新・位置/天気・署名・公開方式は変更せず、新しい通信・権限を追加しません。更新前にはJSONを退避してください。

実端末でのIME操作・TalkBackの読み上げ・同一署名の正式APKによる更新後の記録保持は未確認です。
[本版の確認記録](../RELEASE_CHECKLIST_v0.1.5.md)と[旧気分の互換性](../backup.md)を参照してください。
オーナーがmainへマージすると自動公開対象となります。実装担当はマージ・タグ作成・先行公開を行いません。
