# カレンダーから日付を選ぶ

通常は全件のタイムラインです。上部のカレンダーアイコンを押すと月間カレンダーを開きます。
初回は今月、日付別表示から開いた場合は選択月を表示します。前月/翌月、今月、最新の記録がある月へ移動できます。
曜日は日曜始まりです。投稿がある日にはドットが付き、読み上げでは年月日と投稿件数を確認できます。投稿がない日は選択できません。

1. 投稿のある日を選ぶとカレンダーが閉じ、その日の投稿だけを時系列で表示します。
2. 上部の年月日・件数で絞り込みを確認し、「全件表示」で元の一覧へ戻ります。全件と日付別のスクロール位置は分けて保持します。
3. 日付別表示でも本文や気分の編集・削除を使えます。その日の最後の投稿を削除すると全件へ戻ります。
4. 送信は現在時刻の投稿になり、成功すると全件表示へ戻って新しい投稿へ移動します。保存失敗時は絞り込み・本文・気分を保持します。

カレンダーを閉じるだけでは表示対象を変更しません。JSONの全件復元が成功した場合は全件表示へ戻り、復元された最新の投稿を表示します。
「バックアップ」「設定」は右上の「︙」メニューから開けます。位置・天気やアプリの更新も「設定」から利用できます。

## 日付の基準

投稿日時の正本はUTC epochミリ秒のままです。カレンダーの分類と件数は、端末のローカルタイムゾーンの暦日へ変換し、一覧の日時表示と同じゾーンを使います。
日付の長さを24時間と決めつけず、夏時間や午前0時・月/年境界も扱います。
タイムゾーンを変更して戻ると再計算し、選択日に投稿がなくなった場合は全件へ戻ります。投稿自体の日時・本文・ID・順序・気分・位置/天気は変更しません。

選択日は画面の状態として保持し、バックアップJSONには含めません。Room v3・JSON v2と旧JSONの互換性を維持しています。
外部カレンダーへの送信・同期や新しい権限は追加していません。
